# יציאת מצרים · משחק הרפתקה · Kita

משחק דפדפן (Phaser 3) בשש תחנות לפי ספר שמות א–טו: שעבוד, התיבה ביאור, הסנה, עשר המכות, היציאה וקריעת ים סוף, ובסוף שירת הים.
אתר סטטי, בלי שלב בנייה ובלי פרטי תלמידים. האיורים והצלילים נוצרים בקוד.

- `index.html` – המשחק (`?all=1` פותח את כל התחנות, `?stage=N` קופץ לתחנה)
- `teacher.html` – אזור המורים
- `credits.html` – קרדיטים
- `js/` – art (איורים), audio (צלילים), data (טקסטים ושאלות), core, stages1–3, main
- `vendor/phaser.min.js` – Phaser 3.80.1 (MIT)

באוויר: https://kita-yetziat-mitzrayim.vercel.app
